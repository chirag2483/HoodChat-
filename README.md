# HoodChat

HoodChat is a modern, real-time chat application designed to connect people seamlessly. It offers a user-friendly interface and robust features for an enhanced communication experience.

## Features

- Real-time messaging
- User authentication
- Notification sounds for new messages
- Responsive design for mobile and desktop

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/HoodChat.git
    ```
2. Navigate to the project directory:
    ```bash
    cd HoodChat
    ```
3. Install dependencies:
    ```bash
    npm install
    ```
4. Start the development server:
    ```bash
    npm start
    ```

## Usage

1. Open the application in your browser at `http://localhost:3000`.
2. Sign up or log in to your account.
3. Start chatting with your friends or join group chats.

## Technologies Used

- **Frontend**: React , tailwindcss
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **Real-time Communication**: Socket.IO
